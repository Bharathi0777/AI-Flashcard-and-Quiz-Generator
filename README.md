# Smart Self-Learning - VAC Project

An AI-powered learning platform for students.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Database: MongoDB

## Project Structure
- frontend/ - User Interface
- backend/ - Server & API
- docs/ - Documentation

## How to Run
1. Clone this repo
2. Open frontend/index.html
3. Start backend server
